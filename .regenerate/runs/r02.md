## What this run taught
A second TypeScript build again passed every case, with a different file layout (six modules
instead of four) and different choices on the open replay edge cases. Its one real finding was
again in the spec's own text: a sentence about check order that contradicted itself, written
when I added "unknown_op before input checks" to a sentence that already said "table order".
The builder resolved it the intended way and flagged the wording as loose rather than wrong.
Both TypeScript runs so far have found errors in the prose around the rules, not gaps in the
rules.
