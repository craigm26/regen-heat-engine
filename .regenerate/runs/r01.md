## What this run taught
The first blind build matched the whole suite on its first try, in 19 turns. The one real
finding was an error in the spec itself, not in the build: an example in REQ-WB-003 that I had
typed instead of computing. The builder trusted the formula over the example and said so.
Its other choices were all about inputs nobody sends (bad regexes, missing statuses, `null`
bodies, non-finite coordinates), which is what "open" is for. A TypeScript builder gets
ECMAScript number formatting for free, so this run says little about how hard REQ-CJ-001 and
REQ-CJ-002 are; the Python run will.
