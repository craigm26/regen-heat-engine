## What this run taught
The Python build was the one expected to trip on number text, and it did not: it read
REQ-CJ-001 and REQ-CJ-002, noticed that `repr` and `format` differ from ECMAScript, and
reimplemented both (shortest digits from `repr` via `Decimal`, exact tie rounding via
`Fraction`), plus UTF-16 key ordering. It said so in its build notes. All the cases written to
catch those differences (`20.25`, `-0`, `1e-7`, `1e21`, surrogate keys) passed. Writing the
formatting rules out as algorithms with a table of examples, instead of saying "like
JavaScript", appears to be what made this work. It was also the shortest run of the four
(13 turns).
